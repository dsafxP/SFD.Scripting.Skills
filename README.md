# Skills

Skills for AI assistants that scaffold, code and exemplify Superfighters Deluxe extension scripts

[![GitHub License](https://img.shields.io/github/license/dsafxP/SFD.Scripting.Skills)](LICENSE)

</div>

## 💡 Skills

### sfd-api-templates

Scaffolds and builds a Superfighters Deluxe script project from the `SFDScript` template, wires up the game SDK via `LibrarySetup`, and produces the loadable `.txt` script. Use whenever someone wants to create or set up a script as it handles the project, not the API.

### sfd-api

Teaches how to write script code against the in-game API. Covers the `Game` singleton, the `OnStartup`/`AfterStartup`/`OnShutdown` lifecycle hooks, events, and how to navigate the proprietary API with bundled reflection scripts. Use for any gameplay logic written inside a script.

### sfd-api-examples

A library of vetted, worked script examples for specific features: mines, drones, joints, player damage/input, raycasting, storage, fire, modifiers, victory conditions, visual debugging, and more. Use when implementing a concrete feature and wanting to see it assembled end-to-end.
